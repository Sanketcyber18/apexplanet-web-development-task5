# SanketSpace — ApexPlanet Task 5 Capstone Project

**Created by Sanket Sharma**

SanketSpace is a responsive, local-first personal productivity web application built using HTML5, CSS3 and vanilla JavaScript.

## Features

- **Personal dashboard:** welcome panel, date-aware greeting and live workspace statistics.
- **Task manager:** create tasks, set priority, mark complete, filter by status and delete or clear completed tasks.
- **Quick notes:** save and delete short notes.
- **Focus timer:** 25, 15 and 5-minute presets, start/pause/reset controls and completed-session tracking.
- **Persistent data:** tasks, notes, theme and daily focus minutes are stored in browser localStorage.
- **Responsive interface:** collapsible mobile navigation and layouts for desktop, tablet and phone.
- **Theme switch:** toggle between dark and light appearance.

## Run the project

1. Download and extract the ZIP.
2. Open `Sanket_ApexPlanet_Task5` in VS Code.
3. Open `index.html` with Live Server, or open it directly in a modern browser.
4. Add a task and note, refresh the page, and verify that they remain saved.

No build tools, package installation, server or API key is required.

## Project files

- `index.html` — semantic page structure
- `style.css` — styling, responsive breakpoints and reduced-motion support
- `app.js` — task manager, notes, timer, theme and localStorage logic

## Performance and compatibility notes

- Uses lightweight vanilla JavaScript without a framework.
- Loads the application script with `defer`.
- Uses CSS shapes and gradients instead of large decorative image files.
- Uses event listeners and DOM updates without repeated page reloads.
- Uses standard browser APIs and responsive CSS.
- Includes accessible labels, status announcements and reduced-motion handling.
